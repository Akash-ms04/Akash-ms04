## Featured Projects

### 1. Puma Sales Analysis Dashboard

**Tools:** Power BI, Power Query, DAX

- Analyzed over 5,000 rows of sales data.
- Built a five page dashboard covering executive overview, sales performance, products, regions, and customers.
- Designed a star schema data model.
- Analyzed revenue, profit, units sold, orders, and profit margins.

### 2. Nike Retail Sales Analysis Using SQL

**Tools:** PostgreSQL, SQL, Microsoft Excel

- Analyzed over 10,000 retail sales transactions.
- Normalized the dataset into four relational tables.
- Examined retailer performance, product demand, regional sales, and operating profit.
- Used business questions to guide sales analysis.

### 3. Logistics Dashboard

**Tools:** Tableau

- Analyzed approximately 4,900 orders and revenue of approximately 487.6 million in the dataset's reporting units.
- Evaluated delivery efficiency, shipping costs, carrier performance, and warehouse operations.
- Built dashboard views for executive overview, delivery performance, revenue and cost, and warehouse intelligence.
- Used calculated fields, filters, and dashboard actions.

### 4. Retail Sales Analysis Dashboard

**Tools:** Microsoft Excel, Pivot Tables

- Analyzed 315 retail transaction records.
- Evaluated sales, profit margins, regional performance, and product categories.
- Built an interactive dashboard for retail business metrics.
